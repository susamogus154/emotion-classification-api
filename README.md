An API taking in audio files and outputting the probabilities of the main emotion expressed.

[Live demo of this API](https://emotion-classification-frontend.vercel.app/)

Data is very large so it is not put here, but can be found at https://www.kaggle.com/datasets/uldisvalainis/audio-emotions?resource=download-directory.
This dataset is a combination of several audio datasets: CREMA-D, TESS, RAVDESS, SAVEE.
